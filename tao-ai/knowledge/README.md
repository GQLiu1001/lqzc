# Knowledge Base Layout

`knowledge/` 用于补充 Skill 之外的可检索业务文档，交给 RAG 统一切块、过滤和索引。

目录约定：

- `knowledge/mall/`：商城侧的规则、物流、商品咨询、售后材料
- `knowledge/warehouse/`：仓储侧的库存规则、审批规范、作业 SOP
- `knowledge/shared/`：跨域共享的回答规范、权限边界、运维检查单

编写建议：

- 文件名尽量表达清楚业务主题，便于生成稳定的 `doc_id`
- 每篇文档使用一个明确的一级标题，正文写成可直接引用的业务规则
- 内容以事实规则、时效、限制条件、角色边界为主，避免写纯口号
- 若文档归属某个场景，使用子目录区分，例如 `aftersale_policy/`、`outbound_approval/`

首批补齐内容：

- 商城：退款换货、商品选型、物流承诺、票券支付政策
- 仓储：高风险出库审批、库存异常判定、库存查询与流水复核
- 共享：回答与权限边界、重建与发版检查单

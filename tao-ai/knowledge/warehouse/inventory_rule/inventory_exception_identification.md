# 库存异常判定、盘点与排查 SOP

## 核心判定原则

库存异常不能只看某个时点的库存快照，必须同时结合以下四类信息综合判断：

- 近期出入库流水
- 订单占用和调拨占用情况
- 人工修正（冲正、盘盈、盘亏）记录
- 同批次、同商品在其他仓库的库存变化

仅凭单一信号（如"今天库存突然少了"）不足以下异常结论。

## 异常信号分级

### 一级异常（立即阻断）

- 当前库存为负数
- 订单占用量超过 `on_hand`
- 连续 3 天库存下降但无任何出库流水
- 同一 SKU 在 24 小时内被冲正 3 次以上

### 二级异常（需要人工复盘）

- 日出库量超过近 30 天平均日出库量的 **3 倍**
- 近 7 天盘盈盘亏总量超过库存总量的 **2%**
- 同一批次在多仓出现相反方向的库存变化（一仓暴增、一仓暴减）
- 手工修正频率较上月环比上升 50% 以上

### 三级异常（观察）

- 单日库存波动 10% 以上，但有对应流水支持
- 批次过期临近但仍有较大余量
- 库存快照刷新延迟超过 **2 小时**

## 标准排查步骤

1. **取快照**：先查当前库存，确认 `on_hand / available / reserved / damaged`
2. **查流水**：再查近 7-30 天库存流水，按 `source_type` 分组核对
3. **对订单**：对照订单、调拨、冲正记录，找出异常波峰或缺口
4. **跨仓比对**：如涉及调拨，检查源仓和目标仓是否都有对应流水
5. **暂停高风险动作**：在人工复盘前，暂停该 SKU 的大额出库和调拨
6. **出具报告**：排查结论必须引用具体流水 ID 和发生时间，不得模糊

## 盘点流程

- **全盘**：每季度末或重大盘点周期执行，涉及全仓全 SKU
- **循环盘点（Cycle Count）**：按 ABC 分类，A 类商品月盘、B 类季盘、C 类年盘
- **异常盘**：发现一级异常信号后立即触发的临时盘点
- 盘点期间应临时冻结该 SKU 的出入库，避免并发写入干扰
- 盘点单必须由双人执行并签字，不允许单人闭环

## 冲正与修正

- 冲正记录类型为 `adjust`，必须关联盘点单号或异常工单号
- 正向冲正（盘盈）和负向冲正（盘亏）分别记录，不允许合并
- 单次冲正数量超过 100 件或金额超过 1 万，需仓库主管审批
- 连续 3 次冲正未查出根因的 SKU，升级为重点监控商品
- 所有冲正记录不可删除，只能用反向冲正抵消

## 应急处置

- 出现一级异常后，系统自动锁定该 SKU 的出库工具
- 锁定期间，Agent 查询库存可以返回快照，但不得发起任何出库申请
- 解锁需要仓库主管通过人工工单确认，不走自动审批
- 异常处置完成后，必须产出复盘报告并归档至异常知识库

## 与审批链路的协同

- 存在未解决异常的 SKU，出库审批默认进入高风险分级
- 异常期间即使走完审批流程，实际 WMS 执行仍会被阻断
- 异常解除前，禁止跨仓调拨作为"绕过异常"的手段
- Agent 回答客户或仓管询问时，应明确披露该 SKU 处于异常状态

## 回答约束

- 若只有库存快照、没有流水依据，应明确说"当前证据不足以判定异常"
- 涉及是否允许继续出库时，应提示走审批或人工复核
- 不得以推测结论作为异常判定的依据，必须引用具体流水
- 对客户（customer）不得披露仓库异常细节，仅告知"商品暂不可售"

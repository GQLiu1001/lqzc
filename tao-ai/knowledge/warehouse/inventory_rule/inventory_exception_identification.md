# 库存异常判定与排查 SOP

## 核心判定原则

库存异常不能只看某个时点的库存快照，必须同时结合近期出入库流水、订单占用和人工修正记录判断。

## 常见异常信号

- 当前库存与最近流水累计结果明显不一致
- 日出库量超过近 30 天平均日出库量的 3 倍
- 连续 3 天库存下降但没有对应订单或出库记录
- 冲正、盘盈盘亏、手工修正频率异常升高

## 标准排查步骤

1. 先查当前库存，确认 `on_hand / available / reserved`
2. 再查近 7-30 天库存流水，核对出入库来源
3. 对照订单、调拨、冲正记录找出异常波峰或缺口
4. 必要时暂停高风险出库，待人工复盘后再恢复

## 回答约束

- 若只有库存快照，没有流水依据，应明确说明“当前证据不足以判定异常”
- 涉及是否允许继续出库时，应提示走审批或人工复核

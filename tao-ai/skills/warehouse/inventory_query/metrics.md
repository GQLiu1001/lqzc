# 库存指标定义

## 核心指标
- **on_hand（在库数量）**: 当前实际在仓库内的总数量
- **available（可用库存）**: 可被新订单占用的数量 = on_hand - reserved
- **reserved（预留数量）**: 已被订单占用但尚未出库的数量
- **in_transit（在途数量）**: 已出库但尚未送达的数量

## 流水类型
- **入库（log_type=1）**: 采购到货、退货入库
- **出库（log_type=2）**: 订单出库、调拨出库
- **调拨（log_type=3）**: 仓间转移
- **冲正（log_type=4）**: 数据修正、盘盈盘亏

## 异常判断参考
- 日出库量 > 月均日出库量 × 3 → 可能异常
- 库存连续 3 天下降且无对应订单 → 需排查
- 冲正操作频繁 → 可能存在管理问题

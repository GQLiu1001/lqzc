# 订单查询技能

## 适用问题
- "帮我查一下最近的订单"
- "订单 ORD20250101001 现在到哪了"
- "这个订单退款到哪一步了"
- "为什么还没发货"
- "我买的商品什么时候到"

## 工具使用指引

### 无订单号时
优先调用 `my_order_query` 获取最近订单列表，定位目标订单后再查详情。

### 有明确订单号时
直接调用 `order_detail_query(order_no=...)` 查询订单状态、金额、支付和发货信息。

### 需要物流信息时
在已有订单号的前提下，调用 `logistics_trace_query(order_no=...)` 查询物流轨迹。
如果用户同时问了订单状态和物流，应组合调用 `order_detail_query` + `logistics_trace_query`。

## 权限约束
- 所有订单查询必须绑定当前用户身份，不允许查询其他用户的订单
- 工具内部自动从 runtime context 获取用户 ID，无需手动传 customer_id
- 查询失败时如实说明"未查询到"，不要编造订单信息

## 回答格式
- 订单状态使用中文描述（待支付/待发货/配送中/已完成/已取消）
- 金额保留两位小数
- 时间使用 yyyy-MM-dd HH:mm 格式
